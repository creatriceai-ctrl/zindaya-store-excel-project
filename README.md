# Vindaya Sales & Orders Dashboard

An interactive Excel dashboard built to analyze sales performance, customer demographics, order status, and distribution channels.

## 📌 Project Overview

This project provides a comprehensive analysis of sales data to help understand purchasing behaviors, top-performing sales channels, and demographic breakdown.

Key Metrics & Insights:

* Orders vs Sales: Monthly breakdown of order volume versus total sales amount.
* [Screenshot 2](Screenshot%202026-09-29%20110505.png)

* Sales by Gender: Breakdown of purchases between Men (59%) and Women (41%).
* [Screenshot 3](Screenshot%202026-09-29%20110517.png)

* Age vs Gender: Categorization of orders by age groups (Adults, Seniors, Teenagers).
*[Screenshot 4](Screenshot%202026-09-29%20110533.png)

* Order Status: Visual analysis of order outcomes (Delivered, Refunded, Cancelled, etc.).
* [Screenshot 5](Screenshot%202026-09-29%20110545.png)

* Top 5 States: Identification of the highest-performing regions (Maharashtra, Karnataka, Uttar Pradesh, Telangana, Tamil Nadu).
* [Screenshot 6](Screenshot%202026-09-29%20110558.png)

* Order Channels: Sales performance across platforms like Amazon, Flipkart, Myntra, Meesho, and Ajio.
* [Screenshot 7](Screenshot%202026-09-29%20110618.png)



 Tools & Technologies Used

* Microsoft Excel: Data Cleaning, Pivot Tables, Pivot Charts, Slicers, and Dashboard .


 Key Takeaways & Insights

1. Top Demographics: Adults represent the largest customer base.
2. Sales Channels: Amazon and Flipkart drive the highest volume of orders.
3. Regional Performance: Maharashtra and Karnataka generate the highest sales revenue.
